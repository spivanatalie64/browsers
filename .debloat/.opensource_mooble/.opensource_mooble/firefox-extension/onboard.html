Installation & startup

Repository README (open in your file manager):

.opensource_mooble/README.md

Quick steps (example):

  1. Make sure you have Searx and other deps installed per README.
  2. From the repo root: ./start-searx.sh and then start the Mooble server (see README).
  3. Return here and click Retry or Open Mooble.

If you want Mooble as your new tab/homepage, copy the autostart files or configure the browser; see README.
