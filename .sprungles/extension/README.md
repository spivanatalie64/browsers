Sprungles extension (unpacked)

Files created under this folder:
- manifest.json
- background.js
- agent-runtime.js
- content-script.js
- popup.html
- popup.js
- agents/ (copied from your agents directory) including agents/index.json

IMPORTANT: The extension/agents directory is generated from the source
agents and should not be edited manually. Run `make build` in this
directory to regenerate the agents index and copy the latest agent
markdown files from the source repository.

Build step
----------

To regenerate the generated agents and index.json run:

  make build

This runs the scripts/gen_index.py script which copies .md files from
the source agents directory into extension/agents/ and writes
extension/agents/index.json. The script is idempotent and safe to run
multiple times.

How to load for testing:
1. Open Chrome (or Chromium-based browser) and go to chrome://extensions
2. Enable Developer mode (top-right)
3. Click "Load unpacked" and select this extension folder: extension/ (the directory containing manifest.json)
4. Open any webpage; the content script is injected automatically. Click the Sprungles extension button and use the popup to list and run agents.

Notes & follow-ups:
- This runtime is intentionally minimal: it fetches agent markdown and simulates execution in the content script.
- Consider adding a stricter Content Security Policy and narrowing host_permissions.
- To implement a real agent interpreter, add a safe sandboxed worker that interprets agent markdown and runs authorized actions only.
- Consider moving web_accessible_resources to a tighter set or use dynamic fetch via chrome.runtime.getURL with explicit files.

Developer targets:
- Run tests: `python3 scripts/run_tests.py` (executes tests under extension/tests/)
- Clean generated agents: `make clean` (removes extension/agents/*)

New targets:
- `make test` - runs unit tests and a syntax check (uses only stdlib py_compile)
- `make lint` - runs syntax-only linting using python -m py_compile

Note: do not edit files under extension/agents/ directly; they are generated by the build step.
