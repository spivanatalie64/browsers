# TODO / FIXME Aggregation

This directory contains an aggregated collection of all TODO/FIXME/@todo occurrences discovered in this repository.

How the list was gathered
- Used ripgrep (rg) with the following options:
  - --hidden --no-ignore --text to include hidden and ignored files and treat binary files as text
  - searched for the exact, case-sensitive patterns: TODO, TODO:, FIXME, FIXME:, @todo
  - excluded the .git directory and the docs/todo directory itself from the search
- The raw rg output (format: path:line:match) is saved to all_todos.txt.

Files
- all_todos.txt: Full raw output from rg (path:line:match). This file contains the complete, untruncated set of matches.
- summary.md: Overall counts and top files summary.
- by-top-level/: Per-top-level-directory grouping files. Each file lists matches found under that top-level subtree and a count header.
- README.md: This file explaining how the data was gathered.

How to regenerate
1. From the repository root, run the following command (requires ripgrep):

   rg -n --hidden --no-ignore --text --glob '!.git' --glob '!docs/todo/**' -e 'TODO' -e 'TODO:' -e 'FIXME' -e 'FIXME:' -e '@todo' . | sed 's|^\./||' > docs/todo/all_todos.txt

2. Re-run the grouping/summary steps (filtering by the first path component) to update the by-top-level files and summary.md. You can script this in a short shell script; the existing files in docs/todo/ were generated by an automated process.

Notes
- all_todos.txt contains the full un-truncated output. Per-group files under by-top-level/ may be truncated to keep them readable; truncated files include a note at the top.
- This process only writes files under docs/todo/ and does not modify other repository files.
